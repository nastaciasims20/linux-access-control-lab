# linux-access-control-lab
Linux File Permissions & Access Control Lab
I built this lab in Ubuntu to practice file permissions, user accounts, and access control. I created restricted and public files, tested access using a separate user account, and troubleshot directory permissions to understand how Linux helps protect sensitive information.
I Practiced:
Creating Linux users and directories
Setting file permissions with chmod
Testing access permissions
Troubleshooting directory access
Understanding basic access control
Results:
The test user was denied access to the HR and Finance files but could read the Public file after I corrected the directory permissions.
Tools:
Ubuntu Linux
VMware Fusion
Linux Terminal
