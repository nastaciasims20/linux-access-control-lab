# linux-access-control-lab
Linux File Permissions Lab
For this project, I used Ubuntu to learn how Linux file permissions work and how they can be used to protect sensitive information.
I created folders for HR, Finance, and Public files, then set different permissions to control who could access them. I also created a separate user account to test whether it could open each file.
At first, I ran into an issue with accessing the Public folder. After adjusting the directory permissions, I was able to access the file successfully.
What I Learned:
How to set file permissions using chmod
How to create a separate Linux user
How to test file access
How directory permissions affect access to files
Why access controls matter when protecting sensitive information
Tools Used:
Ubuntu Linux
VMware Fusion
Linux Terminal
